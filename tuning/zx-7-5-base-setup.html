Kyosho Lazer ZX-7.5 base setup

A first setup for a stock 17.5 Lazer ZX-7.5 on small, tight, high-bite indoor clay, where a good local driver turns about 27 laps in just over 5 minutes.

Last edited: November 25, 2026 · Dirt / clay, 17.5 stock class

Starting points, not gospel. These numbers come from general tuning guidance, not measured results from this garage. Change one thing at a time.

The plan for this car

  • Class and power: 17.5 stock, HobbyWing Bandit 17.5 with the same ESC as the RC10T7.
  • Tires: JConcepts slick/smooth-style tires, silver compound, front and rear.
  • Track: small, tight, and aggressive; smooth high-bite clay.

Start from Kyosho's manual. I could not find a published ZX-7.5 setup sheet to quote, so the column marked "Kit setting" is yours to fill in from the manual. The recommended column is where I would move away from the kit on this kind of track.

Base setup

SettingKit setting (fill in from manual)Recommended start for high-bite clay
Shock oil, front30-35wt (Kyosho #350-#400)
Shock oil, rear27.5-32.5wt (Kyosho #300-#350)
Springs, front / rearMedium-firm front / medium rear (one step firmer than kit if kit feels soft)
PistonsKit pistons first; then 1.6 to 1.7 holes if you want more or less damping
Front diff5,000-7,000 oil (ball diff: snug but slipping on a hard bump)
Center diff / slipper3,000-5,000 if fluid or gear; check what the ZX-7.5 has
Rear diff3,000-5,000 oil
Shock positionTops mid-position, bottoms mid; tops slightly outward (firmer) for smooth clay
Camber F / R-1.5 to -2 / -1 to -1.5 degrees
Toe F / R0 to 1 degree out / 2-3 degrees in
CasterMid position; more if the car pushes off the corner
Anti-squat1-2 degrees to start
Ride heightLow and level; about 20-24 mm front, 22-26 mm rear is typical

The first night of testing

  1. Run the kit setup for a pack and note the laps.
  2. Fix the biggest complaint first. Pushing on entry: soften front springs or thin front oil. Loose on exit: more rear toe-in or a looser center diff.
  3. Change one thing, run a pack, and write it down.

Things to plan for

  • Parts support. The ZX-7.5 is no longer a mainstream model, so stock spare arms, hubs, and diff parts before race day.
  • Tires. Check the tires page for what to try when the track changes.
  • ESC. The same ESC as the RC10T7 should work; start with a mild punch and drag brake, and raise them as you learn the car.
